sequenceDiagram
participant U as 用户
participant X as 咸鱼Agent
participant C as 对话Agent
participant O as 订单系统
participant H as 酒店Agent

U->>X: 确认预订
X->>C: 转发

C->>O: 更新订单(CONFIRMED)

C->>X: 发送支付二维码
X-->>U: 展示二维码

U->>X: 已付款
X->>C: 转发

C->>O: 更新订单(PAID)

C->>H: 执行下单
H-->>C: 下单成功

C->>O: 更新订单(BOOKED)

C->>X: 返回成功信息
X-->>U: 预订成功
